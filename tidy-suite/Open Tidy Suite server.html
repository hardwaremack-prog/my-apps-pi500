Tidy Suite server

Run the whole Tidy Suite from this Pi so everyone in the house uses it from their own phone or computer, and each person's work is saved on the Pi.

  • Every app (Tidy, Neat, Spruce, Steady, Ready, Rugged...) at one address: http://<this Pi>:8780
  • Each person picks their name in the apps, so nobody's work gets mixed up
  • Saved work lives in tidy-suite/Saved work - the same folder layout as the Windows version, so you can copy it between a PC and the Pi

Server Room's installer can make it start with the Pi. By hand: python3 ~/Desktop/"My Apps"/tidy-suite/tidy_server.py. It's for your home Wi-Fi: don't forward port 8780 on your router.

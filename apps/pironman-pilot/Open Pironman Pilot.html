Pironman Pilot

Control panel for a Raspberry Pi 5 in a SunFounder Pironman 5 MAX case: the OLED screen, the tower and side fans, the RGB lights and safe overclocking.

  • Fans: quiet curves (Whisper, Silent), a speed curve for the side RGB fans and a live CPU speed limit
  • OLED: your own pages (temperature, clock speed, network, custom text)
  • Overclock with a safety net: it test-boots first and only keeps settings that pass a stability test
Checking…

Only for a Pi 5 in a Pironman 5 MAX case. Install it once (asks for your password):
bash ~/Desktop/"My Apps"/apps/pironman-pilot/install.sh
Then it runs in the background and opens from the Pironman Pilot icon (menu: System Tools).

PiStartup

See everything that starts with your Pi and switch it off or back on. Great for keeping a server lean.

  • Desktop autostart apps, labwc/LXDE/Wayfire autostart lines and @reboot cron jobs
  • System and user services, with how long each took at the last boot (filter: Slowest at boot)
  • Core pieces are locked; risky ones like SSH, Wi-Fi and VNC ask first

Install it once: bash ~/Desktop/"My Apps"/apps/pistartup/install.sh. It lives in Menu > Preferences.
